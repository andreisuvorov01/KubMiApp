## Краткое описание компонентов

### Presentation Layer
- **Screens**: UI экраны на Jetpack Compose
- **ViewModels**: Управление состоянием с Hilt DI
- **Components**: Переиспользуемые UI компоненты

### Domain Layer
- **Models**: Бизнес-модели приложения
- **Repository Interfaces**: Контракты для работы с данными
- **Use Cases**: Бизнес-логика (GetNewsUseCase)

### Data Layer
- **Repository Implementations**: Реализация репозиториев
- **Local (Room)**: Локальное кэширование в SQLite
- **Remote (WebScraper)**: Парсинг данных с сайта kubmi.ru
- **Worker**: Фоновая синхронизация через WorkManager

### Services
- **KioskService**: Watchdog для режима киоска
- **KioskAccessibilityService**: Расширенный контроль киоска
- **BootReceiver**: Автозапуск при загрузке устройства

### Utilities
- **KioskManager**: Управление режимом киоска
- **SecurePreferences**: Безопасное хранение настроек
- **CacheManager**: Управление кэшем
- **ImageLoader**: Загрузка и кэширование изображений
