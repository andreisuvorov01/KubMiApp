# Настройка скринсейвера через SFTP

## Описание

Приложение поддерживает два режима работы скринсейвера:

1. **Новости с сайта** - автоматическая загрузка PDF из раздела "ЧС" на сайте института
2. **SFTP сервер** - загрузка PDF файлов с удалённого сервера

## Настройка SFTP режима

### Данные для подключения к серверу

- **Хост:** 46.254.17.172
- **Порт:** 22 (стандартный SFTP/SSH)
- **Пользователь:** root
- **Пароль:** eS8h882JP9
- **Папка:** /pdf

### Инструкция для Windows

1. Скачайте и установите [WinSCP](https://winscp.net/eng/download.php) или [FileZilla](https://filezilla-project.org/)
2. Запустите программу
3. Создайте новое подключение:
   - Протокол: SFTP
   - Хост: 46.254.17.172
   - Порт: 22
   - Имя пользователя: root
   - Пароль: eS8h882JP9
4. Подключитесь к серверу
5. Перейдите в папку `/pdf`
6. Загрузите PDF файлы перетаскиванием или через меню "Загрузить"

### Инструкция для macOS/Linux

Используйте встроенную команду `sftp` в терминале:

```bash
# Подключение к серверу
sftp root@46.254.17.172

# После ввода пароля (eS8h882JP9):
cd /pdf

# Загрузка одного файла
put /путь/к/вашему/файлу.pdf

# Загрузка нескольких файлов
mput /путь/к/папке/*.pdf

# Просмотр загруженных файлов
ls

# Выход
exit
```

### Альтернативный способ через командную строку (Windows PowerShell/Linux/macOS)

```bash
# Загрузка через SCP
scp /путь/к/файлу.pdf root@46.254.17.172:/pdf/

# Загрузка всех PDF из папки
scp /путь/к/папке/*.pdf root@46.254.17.172:/pdf/
```

## Требования к файлам

- Формат: только **PDF**
- Размер: рекомендуется до 10 МБ на файл
- Ориентация: желательно **альбомная (landscape)** для лучшего отображения
- Приложение автоматически конвертирует PDF в изображения для показа

## Переключение режима скринсейвера

1. Откройте приложение
2. Нажмите на иконку настроек (⚙️) в правом верхнем углу
3. Введите пароль администратора (по умолчанию: `kubmiadmin`)
4. В разделе "Настройки экранной заставки" выберите нужный режим:
   - **Новости с сайта** - использовать PDF из раздела "ЧС"
   - **Сервер SFTP** - загружать с удалённого сервера
5. Нажмите "Показать инструкцию по загрузке файлов" для просмотра данных подключения

## Устранение неполадок

### Не удаётся подключиться к серверу

- Проверьте подключение к интернету
- Убедитесь, что порт 22 не заблокирован файрволлом
- Проверьте правильность введённых данных

### PDF не отображаются

- Убедитесь, что файлы действительно в формате PDF
- Проверьте, что файлы находятся в папке `/pdf` на сервере
- Перезапустите приложение для обновления списка файлов

### Изображения низкого качества

- Используйте PDF файлы с высоким разрешением (минимум 1920x1080)
- Убедитесь, что PDF не содержит только отсканированные изображения низкого качества

## Безопасность

⚠️ **Важно:** Учётные данные SFTP жёстко закодированы в приложении для упрощения использования в киоск-режиме. Для повышенной безопасности:

- Не храните конфиденциальные данные на сервере
- Используйте выделенный сервер только для этого приложения
- Регулярно меняйте пароль SFTP и обновляйте приложение
- Настройте firewall для ограничения доступа к серверу
